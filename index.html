Selamat Datang di E-Portfolio Saya

E-portfolio ini menjadi ruang untuk memperkenalkan diri, mengenal latar belakang daerah asal, melihat lingkungan perkuliahan, merefleksikan pembelajaran selama dua semester, serta menyimpan dokumentasi kegiatan selama mengikuti Program Pendidikan Profesi Guru.

Website ini disusun dengan harapan dapat menjadi catatan bermakna, bukan sekadar dokumen akademik, melainkan refleksi nyata dari proses belajar menjadi seorang guru.
